## 2026-09-26

Крупная переработка после двух сквозных прогонов на чистом VDSina Ubuntu 26.04.1.

- Ubuntu 26.04 в списке поддерживаемых: sudo-rs, chrony, `/tmp` в tmpfs, `ssh.socket` с
  генератором порта, fail2ban с `backend = systemd`.
- Правила для агента: команды только из файла, конфиги через `scp` и `install`, проверка по
  содержимому, ручные шаги в отдельном окне терминала (у `!` в Claude Code нет TTY), два
  режима sudo с выбором пользователя, пароли и passphrase мимо чата.
- Гейт от «я заперся»: семь проверок, таймеры отката на `--on-calendar` (относительные
  перевзводятся каждым `daemon-reload`), объективная проверка консоли и второй сессии.
- Уровни 1 и 2 с критерием «готово» и временем; третий уровень вынесен в `ubuntu-server-admin`.
- Drop-in sshd переименован в `00-hardening.conf`, чтобы cloud-init его не перебивал.
- `unattended-upgrades` проверяется по пакету, таймерам и конфигу сразу: образы хостеров
  бывают с удалённым пакетом при лежащем конфиге.
- Бэкап и Telegram-алерты по выбору пользователя с записью последствий в паспорт. Алерты в
  формате «что случилось, что делать» с эмодзи. Сквозной тест `OnFailure`, восстановление с
  побайтной сверкой, healthchecks.io по желанию.
- Скрипты: `diagnose.sh` с вердиктами и планом по уровням, `set-passwords.sh`,
  `tg-setup.sh`, `restic-env.sh`.
- Раздел 9: аудит `ssh-audit` и `lynis`, контрольная перезагрузка, паспорт сервера, уборка до
  снятия режима B, чеклист. Раздел 10: runbook «Я заперся». В backups.md: runbook «Сервер умер».
- Ubuntu Pro убран из скилла.
